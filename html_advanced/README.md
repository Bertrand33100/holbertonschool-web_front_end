# HTML Avance

## Description du projet

Dans ce projet, nous apprenons a utiliser les balises HTML pour structurer une page web. Pas de CSS, pas de style - la page finale sera "moche" et c'est normal, ce n'est pas l'objectif ici. L'objectif est de maitriser la **structure** d'une page HTML.

**Nom de l'entreprise utilisee dans les pages :** Techium

## Ce que je dois apprendre et retenir

- Quelles directives suivre pour ecrire du HTML valide
- Comment creer le squelette d'une page HTML5
- Comment utiliser les balises semantiques pour structurer une page web
- Quand utiliser `div` vs `span`
- La valeur semantique de `header`, `main`, `footer`, `article`, `nav`, `section`, `aside`
- Comment utiliser les titres (`h1` a `h6`) et pourquoi respecter l'ordre hierarchique
- Comment creer des listes en HTML (`ul`, `ol`, `li`)
- Les differences entre les formats d'images (SVG, GIF, PNG, JPG)
- Comment structurer des donnees dans un tableau (`table`)
- Comment integrer une video dans une page web
- Comment integrer un fichier audio dans une page web
- Comment embarquer du contenu externe (`iframe`, `embed`)
- Comment structurer correctement une page HTML complete
